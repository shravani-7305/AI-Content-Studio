# AI Content Studio

Create a complete responsive web application called "AI Content Creator" for my CSE college project titled "Generative AI Based Content Creation Tool".

Build a professional modern AI-themed website with these pages:

1. Home

2. AI Content Generator

3. SEO Assistant

4. History

5. About

6. Login and Sign Up

7. Dashboard

The main purpose is to allow users to enter a topic, select content type and writing tone, and generate content using Generative AI.

Content types should include Blog, Article, Social Media Post, Advertisement, Product Description, Email, and YouTube Description.

The Generator should have:

- Topic input

- Content type dropdown

- Tone dropdown

- Content length selection

- Keywords input

- Generate Content button

- Generated content display

- Copy, Edit, Save and Download buttons

The SEO Assistant should generate:

- SEO title

- Meta description

- Primary keywords

- Secondary keywords

- Suggested headings

- Hashtags

The History page should show previously generated content with View, Edit, Copy and Delete options.

Create a clean professional UI suitable for a CSE final-year college project. Make it responsive for desktop and mobile.

Use reusable components, proper navigation, loading states, error messages, and sample/demo data where an AI API is not yet connected.

Do not make it just a static landing page. Build the application structure so the features can be connected to a real Generative AI API and database later.
